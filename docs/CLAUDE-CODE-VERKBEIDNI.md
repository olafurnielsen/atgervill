# Verkbeiðni til Claude Code

> Söguleg skrá frá afhendingu 0.3. Verkefnið hét þá „Mannleg íslenska“ og skill-mappan `mannleg-islenska/`; nú heitir það Atgervill og skill-ið `yfirlestur/` (`/yfirlestur`).

Taktu við þróun „Mannlegrar íslensku“ úr þessari möppu. Ég vil fyrst yfirlestur og uppsetningu GitHub-kóðahirslu, og síðan mun Codex fara yfir niðurstöðuna.

Lestu README.md, AGENTS.md, docs/AFHENDING.md og skill-ið í mannleg-islenska/. Ekki gera ráð fyrir að aðgerðir sem lýst er sem næstu skrefum séu þegar útfærðar.

1. Farðu yfir ritstjórnarreglur, merkingartryggð, heimildanotkun, réttindaskráningu, færanleika og prófunaraðferð. Skráðu raunverulega veikleika með dæmum. Greindu sérstaklega á milli sjálfsmats, vélrænna varðveisluprófa og óháðs mats.
2. Keyrðu fyrirliggjandi próf og staðfestu hvað þau gera og gera ekki. Prófaðu hleðslu og beitingu skills í Claude Code ef umhverfið leyfir. Geymdu ný hegðunarúttök sér; ekki yfirskrifa fyrri niðurstöður eða nota þær sem falda fyrirmynd.
3. Lagfærðu staðfestar villur í skjölum, tenglum og pökkun. Skráðu stærri hegðunarbreytingar sem afmarkaðar tillögur. Uppflettiferli og val á breytingartillögum eru næstu þróunarverkefni; ekki lýsa þeim sem tilbúnum án útfærslu og prófana. Ekki byggja sérstakt viðmót í þessari fyrstu afhendingarumferð.
4. Gerðu möppuna að snyrtilegri Git-kóðahirslu. Varðveittu rekjanlegan grunn áður en eigin breytingar fara inn, svo Codex geti borið saman. Staðfestu að engin innri vinnugögn, einkaslóðir eða lyklar fari í hirsluna.
5. Settu hirsluna upp á GitHub fyrir mig. Ef eigandi, heiti eða sýnileiki eru ekki þegar skýr í þessu samtali skaltu leggja til heitið `mannleg-islenska`, hafa hirsluna lokaða að sjálfgefnu og fá aðeins þær nauðsynlegu upplýsingar sem vantar áður en þú stofnar hana. Ekki velja opið leyfi eða birta hana opinberlega án ákvörðunar minnar. Notaðu fyrirliggjandi innskráningu; ekki biðja mig um að líma lykla í spjall. Ef GitHub-aðgang vantar skaltu klára staðbundna undirbúninginn og segja nákvæmlega hvað vantar.
6. Skilaðu stuttri stöðuskýrslu og varðveittu yfirlesturinn í `docs/CLAUDE-YFIRLESTUR.md`. Tilgreindu hirsluslóð, sýnileika, grunn-commit, lokacommit, grein og PR-slóð ef við á. Aðgreindu það sem var prófað frá því sem var ekki prófað og teldu upp eftirstandandi verkefni.

Merking og rödd höfundar ganga fyrir stílfegurð. Miðlungs yfirferð er áfram sjálfgefin. Uppflettingar skulu virka með tiltækum vefverkfærum án kröfu um tiltekinn þjónustuaðila. Ekki gera fullyrðingar um gervigreindargreiningu.
